Technical Architecture & Methodology

A detailed academic walkthrough of the dual-engine synergy: Machine Learning Computer Vision fused with Semantic Web Ontology Reasoning.

Core Academic Distinction: ML vs. Semantic Ontology

Dimension Machine Learning Engine (CNN) Semantic Web Ontology (OWL / SPARQL)
Primary Question Answered "What visual pattern or disease class is likely present in this image?" "What is this disease, what pathogen causes it, what symptoms occur, how severe is it, and what care/prevention applies?"
Input Modality Raw image pixels (224x224 RGB floating-point tensor). Predicted class entity, environmental factors (humidity, temp), and botanical concepts.
Reasoning Mechanism Sub-symbolic convolution layers extracting spatial edge, texture, and chlorosis filters. Symbolic formal logic axioms, description logic (DL), and SWRL rule chaining.
Explainability Black-box statistical probability / Softmax confidence score. Transparent, verifiable semantic paths with human-interpretable clinical justifications.
Handling of New Care Knowledge Requires complete model retraining and dataset relabeling. Immediately updated by adding an OWL triple or SWRL rule in Protégé without retraining.

Protégé OWL Classes
  • :Fruit - Target agricultural host plant
    9 Species
  • :Disease - Phytopathological condition
    15+ Classes
  • :Symptom - Observable morphological lesions
    13 Symptoms
  • :Pathogen - Causative biological organism
    Fungi / Bacteria
  • :Severity - Clinical intensity assessment
    Healthy to Critical
  • :Treatment - Organic, biological & cultural remedies
    Categorized
  • :Prevention - Proactive prophylactic field measures
    Sanitation/Drip
  • :EnvironmentalFactor - Temperature & relative humidity
    Microclimate
SWRL Inference Rules
Rule 1 (Anthracnose Symptom Chaining):
Fruit(?f) ^ affectsFruit(Disease_MangoAnthracnose, ?f) ^ causesSymptom(Disease_MangoAnthracnose, Symptom_BlackSpot) ^ causesSymptom(Disease_MangoAnthracnose, Symptom_Lesion) -> identifiesDisease(?d, Disease_MangoAnthracnose)
Rule 2 (Environmental Severity Escalation):
Disease_MangoAnthracnose(?d) ^ favoredBy(?d, Env_HighHumidity) ^ favoredBy(?d, Env_WarmTemperature) -> hasSeverity(?d, Severity_High)
Rule 3 (Treatment Propagation Axiom):
Diagnosis(?diag) ^ identifiesDisease(?diag, ?dis) ^ treatedBy(?dis, ?treat) -> treatedBy(?diag, ?treat)
Rule 4 (Healthy Tissue Classification):
Diagnosis(?diag) ^ identifiesDisease(?diag, Disease_MangoHealthy) -> hasSeverity(?diag, Severity_Healthy)
